| **Nombre:** | Gestionar nuevas peticiones (CU-005) |
| :--- | :--- |
| **Autor:** | Marcos Sánchez García |
| **Fecha:** | 19/10/2026 |
| **Descripción:** | El sistema deberá permitir administrador gestionar nuevas peticiones |
| **Actores:** | Administrador |
| **Precondiciones:** | Estar logueado en el sistema como un usuario con el rol de empleado además del rol de administrador |
| **Flujo Normal:** | 1.- El usuario accede al sistema como administrador y le da al boton de gestionar nuevas peticiones.<br>2.- El sistema muestra un menu  donde salen las peticiones<br>3.- El admin realiza actualizaciones o borra las peticiones <br>4.- El sistema realiza las actualizaciones correspondientes o borra lo que el administrador haya gestionado. |
| **Flujo Alternativo:** | 4.A.- No hay ninguna petición, el sistema muestra una pantalla vacia.|
| **Poscondiciones:** | Se realizan numerosas actualizaciones y se borran las peticiones al ya haber sido gestionadas |
