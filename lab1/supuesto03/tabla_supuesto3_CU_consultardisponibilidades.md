
| **CU-001** | **Consultar disponibilidades** |
| :--- | :--- |
| **Versión** | 1.0 (Octubre-2026) |
| **Autores<br>Fuentes** | Marcos Sánchez García<br>Enunciado del supuesto práctico y entrevistas |
| **Referencias** | • Actor: Usuario (Empleado / cliente)<br>• Incluye: Buscar elementos y Mostrar calendario<br>•|
| **Descripción** | El sistema deberá permitir al usuario consultar las disponibilidades en un calendario mostrado y ademas que incluya un buscador para encontrar cada uno de los elementos disponibles|
| **Evento activación** | El usuario realiza una consulta para ver las disponibilidades|
| **Pre condición** | Ninguna |
| **Post condición** | Se muestran las disponibilidades pero no se actualiza ni borra nada.|
| **Resultados** | Consulta de todas las disponibilidades, muestra de un calendario y buscador de elementos |
| **Esc. principal** | 1. El Empleado accede al sistema para encontrar un elemento disponible<br>2. El sistema muestra las disponibilidades a través de un calendario y deja acceso a un buscador<br>3. El usuario introduce un elemento en el buscador.<br>4. El sistema filtra la muestra de disponibilidades hacia el elemento indicado<br> |
| **Alternativas** | ninguna |
| **Excepciones** | **Al paso 4:**<br>1. El elemento introducido no esta disponible(la pagina no muestra nada y un calendario sin ninguna marca de disponibilidad)<br> |
| **Importancia** | Muy importante |
| **Estado** | Aceptado |
| **Comentarios** | Es necesario que el calendario ayude al usuario a saber que esta disponible y que no |
